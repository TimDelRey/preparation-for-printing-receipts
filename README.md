go build -o Receipter ./cmd/worker# Receipter

CLI-утилита для генерации Excel-файла с квитанциями для печати.

## Как использовать

1. Соберите бинарник:

```bash
go build -o Receipter ./cmd/worker
```

2. Положите рядом с бинарником исходный файл:

```text
work_doc_4.xlsx
```

3. Запустите программу:

```bash
./Receipter
```

4. Рядом с бинарником появится результат:

```text
Receipts.xlsx
```

## Важно

- Исходный файл должен называться строго `work_doc_4.xlsx` (за строгим форматом файла просьба обратиться ко мне напрямую).
- Программа ищет исходный файл в той же папке, где находится бинарник.
